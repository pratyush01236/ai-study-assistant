🧠 AI Study Assistant

A beginner-friendly study assistant project designed to help students learn technical topics, prepare for exams, practice interview questions, and create quick revision notes.

The project demonstrates how structured prompts and Python can be used to organize common study tasks.

✨ Features

- 📖 Explain technical concepts in simple language
- 📝 Generate exam-oriented answers
- 🎯 Practice interview questions
- 📚 Create quick revision notes
- 💡 Organize study prompts by learning mode

🛠️ Technologies

- Python 3
- Prompt Engineering
- AI-Assisted Learning
- Command Line Interface

▶️ How to Run

Clone the repository:

git clone https://github.com/pratyush01236/ai-study-assistant.git

Open the project folder:

cd ai-study-assistant

Run the program:

python assistant.py

🎓 Study Modes

The assistant supports different learning modes:

Mode| Purpose
Explain| Understand a topic simply
Exam Answer| Prepare exam-oriented answers
Interview| Practice technical questions
Revision| Create quick revision material
